# Sixt Holdings Contact Page

Place this `contact` folder in the root of the GitHub Pages repository for sixtholdings.com.

URL:
https://sixtholdings.com/contact/

Main navigation link:

```html
<li>
    <a href="/contact/">Contact</a>
</li>
```

## Important
The form uses FormSubmit and sends submissions to chadsixt@gmail.com.

On the first submission, FormSubmit normally requires you to activate the form from an email sent to the destination address. Check chadsixt@gmail.com and complete that activation before relying on the form for customer inquiries.
